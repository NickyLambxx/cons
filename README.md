# PrepMate — Интерактивная Конституция РФ

Учебный веб-сайт для подготовки к ОГЭ и ЕГЭ по обществознанию.  
Живой сайт: [prep-mate.ru](https://prep-mate.ru)

## Что внутри

- 📖 Все главы Конституции РФ с авторскими пояснениями к каждой статье
- 🔍 Умный поиск по статьям и ключевым словам
- 🎯 56 заданий №13 и 40 заданий №23: 50/35 по опубликованным материалам ФИПИ и 6/5 адаптаций по печатным сборникам 2023–2026 годов; книжные варианты и проект демоверсии 2027 года помечены отдельно
- 🃏 Карточки терминов
- 📝 Заметки, статусы и прогресс чтения
- 📱 Быстрый перенос результатов тренировок через QR-код
- 💾 Полная резервная копия в JSON: статьи, заметки, избранное, настройки и результаты тренировок; файл можно перенести между устройствами
- 💾 Продолжение незаконченных тренировок после перезагрузки
- ⌨️ Управление ответами клавишами 1–5 и свайпы в карточках
- 📱 Работает как приложение на телефоне (PWA)

## Проверка учебных данных

По состоянию на октябрь 2026 года в №13 входят пять опубликованных вариантов и 45 дополнительных заданий открытого банка ФИПИ. Для всех заданий банка ответы ранее проверены на сайте ФИПИ; совпадающие и почти одинаковые варианты убраны. В №23 включены пять опубликованных вариантов и 30 заданий действующего конституционного формата из открытого банка; три варианта с одинаковыми тройками ответов убраны. Задания прежнего формата не подмешиваются ради количества. У каждого задания №23 есть полное условие, изложенное своими словами, и требования к оформлению ответа; для заданий ФИПИ доступна ссылка на оригинал. Ориентиры ответов к заданиям банка составлены по Конституции и не выдаются за официальные критерии ФИПИ.

Словарь и колода «Все темы» содержат по 80 понятий. «Микс» содержит 50 разных вопросов за серию: 20 терминов, 15 исправлений утверждений и 15 вопросов о полномочиях или ведении. Незавершённая серия из прежних 20 вопросов дополняется до 50 без потери результата.

Тренажёр «Исправь утверждение» содержит 50 авторских вопросов по действующей Конституции. Ключи шести новых книжных вариантов №13 сверены с таблицами ответов сборников и текстом Конституции. Для пяти новых вариантов №23 приведены пересказанные ориентиры из опубликованных книжных ответов; это не официальный ключ ФИПИ, возможны другие верные формулировки.

## Проверки публикации

`pnpm run predeploy` проверяет код и данные до отправки. После отправки в `main` GitHub Actions дожидается новой версии на сайте и проверяет поиск, №13, №23 и перенос прогресса в браузере с размерами компьютера, планшета и телефона. Вручную те же проверки запускаются командами `pnpm run smoke:live` и `pnpm run smoke:live:ui`.
